Learning roadmap

A pragmatic order of attack. Each phase builds on the last; pick one cloud in phase 3 and go deep rather than wide — the concepts transfer.

Phase 1

Foundations

Python + SQL until they're reflexes. Model a small star schema by hand. (~4–6 weeks)

Phase 2

Distributed processing

Spark internals, then PySpark hands-on: DataFrames, joins, partitions, tuning. (~4 weeks)

Phase 3

One cloud, deep

AWS, Azure, or GCP — storage, warehouse, streaming, IAM. Take the cert path as a syllabus. (~6 weeks)

Phase 4

Lakehouse & warehouse

Databricks (Delta Lake, Unity Catalog) and Snowflake fundamentals. (~3–4 weeks)

Phase 5

Orchestration & ops

Airflow DAGs, plus the ETL tool your shop uses (SSIS / NiFi). Monitoring & alerting basics. (~3 weeks)

Phase 6

Design & ML

DDIA, system-design interviews, feature pipelines and MLOps handoffs. (ongoing)
